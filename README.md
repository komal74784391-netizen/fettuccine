This repository will contain the official implementation of **FETTUCCINE**,
an end-to-end brain-to-text decoding framework for mobile devices (NeurIPS 2026).

The code is under internal review ahead of the camera-ready release. The
repository is public so that reviewers and collaborators can follow the planned
layout; it does not contain a working implementation yet.

## Planned layout

- `src/` — training and decoding code (not yet available)
- `data/` — preprocessing fixtures (empty until release)
- `tests/` — regression tests (not yet available)
- `results/` — evaluation logs (empty)
